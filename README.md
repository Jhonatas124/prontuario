# Prontuário de Bolso

Web app pessoal de saúde (PWA) pra iPhone: hábitos do dia com gamificação, peso com data/hora/local,
exames com gráfico de cada resultado, consultas e ficha.

- Não tem servidor nem conta: os dados ficam só no aparelho (IndexedDB do Safari).
- Backup e restauração por arquivo `.json` (Ajustes › Exportar / Importar).
- Visualizador de PDF embutido (pdf.js, licença Apache 2.0).

Publicação: GitHub Pages, branch `main`, pasta raiz. No iPhone: abrir no Safari › Compartilhar › Adicionar à Tela de Início.
